# SONIQ — versiuni publicate

Aici stau doar versiunile gata de instalat ale **SONIQ**, aplicația de radio online cu posturile din România
(naționale, locale pe județe și online), pentru telefon, tabletă, Google TV și Android Auto.
Codul sursă nu e în acest repo.

SONIQ își ia singur actualizările de aici (din *Releases*): verifică o dată pe zi, iar din ⋮ → „Caută actualizări”
se poate verifica oricând. Android instalează doar APK-uri semnate cu aceeași cheie ca SONIQ, deci un fișier
străin nu poate înlocui aplicația.
